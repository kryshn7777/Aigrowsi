# AIGROW — 3D + glass mockup

Single-file website mockup for AIGROW: a Three.js physically based glass core with chrome / glass / filament rings (bloom, tone mapping), under a glassmorphism UI.

Open `index.html` in a browser. It needs internet: Three.js r170 loads from jsDelivr and fonts from Google Fonts.

- Falls back to a static CSS orb if WebGL fails; respects `prefers-reduced-motion`.
- Copy comes from the AIGROW brief. The contact CTA has no email wired in — connect a real contact route before launch.
